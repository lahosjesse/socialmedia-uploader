# Socialmedia Uploader

Public website and legal pages for the personal desktop application **Socialmedia Uploader**.

## Project structure

- `index.html` — public application homepage.
- `terms.html` — Terms of Use.
- `privacy.html` — Privacy Policy.
- `assets/` — public visual assets.
- `docs/projeto.md` — project purpose and publishing flow.
- `docs/CHANGELOG.md` — permanent change history.
- `docs/VERSION` — current semantic version.

See [project documentation](docs/projeto.md) and [changelog](docs/CHANGELOG.md).

## Security

This repository contains no API credentials, OAuth tokens, passwords, sessions, cookies, or user media.
