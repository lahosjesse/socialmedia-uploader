Personal desktop app

Socialmedia Uploader

Socialmedia Uploader helps its owner upload local videos to authorized social-media accounts through the platforms' official APIs.

How it works

  • The account owner authorizes access using the platform's official OAuth screen.
  • Videos are selected locally and transferred directly to the selected platform.
  • API credentials and access tokens remain on the authorized local computer.

TikTok integration

The TikTok integration uses Login Kit and the Content Posting API. Sandbox and unaudited use is restricted to authorized test accounts and platform-imposed privacy limits.
