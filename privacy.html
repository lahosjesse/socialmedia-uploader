Privacy Policy

Effective date: August 27, 2026

1. Scope

This policy applies to Socialmedia Uploader, a personal desktop tool operated by the GitHub account lahosjesse. The public website is static and does not accept accounts, uploads, forms, advertising, or analytics.

2. Data handled by the desktop app

When the owner connects an account, the app handles OAuth access and refresh tokens, account identifiers, selected video files, captions, publication settings, API receipt identifiers, and publication status. These items are used only to perform actions requested by the authorized account owner.

3. Where data goes

Selected media and publication information are sent directly from the local computer to the official API of the chosen social platform. For TikTok, this includes TikTok Login Kit and the Content Posting API. TikTok processes that information under its own privacy policy and platform terms.

4. Local storage

Credentials and tokens are stored only in local environment or secrets files on the authorized computer. Local operational logs may record timestamps, results, error messages, and API receipt identifiers. Passwords and OAuth tokens must not be written to logs or committed to Git.

5. Sharing and sale

The operator does not sell personal data and does not operate a server or database that collects user credentials or uploaded media. Data is disclosed only to the selected platform as necessary to complete an authorized action, or when required by law.

6. Retention and deletion

The owner controls local files and may delete tokens, logs, and media from the computer at any time. OAuth access can also be revoked from the connected platform's account settings.

7. Security

The app uses official OAuth and API endpoints where available. No security method is perfect; the owner is responsible for protecting the local computer and revoking access if compromise is suspected.

8. Contact

Questions and deletion requests may be submitted through the public GitHub issue tracker. Do not include passwords, tokens, private media, or other secrets in an issue.

9. Changes

Material changes will be published on this page with a new effective date.
